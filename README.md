# vaultnote

Vault validation gates for note inputs before they hit prod.

**Site:** https://theworker02.github.io/vaultnote/

## Install / run

```bash
git clone https://github.com/theworker02/vaultnote.git
cd vaultnote
node src/cli.js
node --test
```
